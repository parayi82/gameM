# Guía de etapas procesales (mapa de referencia)
CIVIL / FAMILIAR (escrito tradicional; el CNPCF entra gradualmente por entidad): demanda y auto admisorio (o prevención o desechamiento) → emplazamiento → contestación, excepciones y reconvención → vista/réplica/dúplica cuando proceda → audiencia previa y de conciliación → ofrecimiento, admisión y desahogo de pruebas → alegatos → citación y sentencia → revocación/apelación → amparo directo → ejecución. En familiar, las medidas provisionales, alimentos, guarda y custodia y convivencias pueden tramitarse incidentalmente en cualquier etapa.

MERCANTIL: Ejecutivo mercantil: demanda con título ejecutivo → auto de exequendo (requerimiento de pago, embargo, emplazamiento) → contestación y excepciones (8 días) → pruebas → alegatos → sentencia → apelación → remate. Oral mercantil: demanda → emplazamiento → contestación → audiencia preliminar → audiencia de juicio → sentencia. Ordinario mercantil: demanda → contestación (15 días) → pruebas → alegatos → sentencia.

LABORAL (reforma 2019): conciliación prejudicial y constancia de no conciliación → demanda → admisión o prevención → emplazamiento y contestación (15 días hábiles), reconvención → réplica (8 días) → contrarréplica (5 días) → audiencia preliminar → audiencia de juicio y sentencia → amparo directo → ejecución.

AMPARO: Indirecto: demanda → admisión, prevención o desechamiento → suspensión provisional e incidente (suspensión definitiva) → informes justificados → audiencia constitucional → sentencia → revisión (10 días). Directo: presentación ante la autoridad responsable → admisión por el Tribunal Colegiado → amparo adhesivo y alegatos (15 días) → sentencia. Recursos: queja, revisión y reclamación (verificar plazos).

PENAL ACUSATORIO (CNPP): investigación inicial y complementaria (control de detención, imputación, vinculación, medidas cautelares, cierre) → etapa intermedia (acusación, descubrimiento, audiencia intermedia, auto de apertura) → juicio oral (fallo, individualización, sentencia) → apelación → amparo. Considera salidas alternas y procedimiento abreviado.

Escritos frecuentes: contestación de demanda, desahogo de vista o de prevención, ofrecimiento de pruebas, objeción de documentos, alegatos, revocación o apelación, incidentes, autorización de abogados y domicilio procesal, copias certificadas, acuse de rebeldía o preclusión, solicitud de audiencia, cumplimiento de requerimiento, impulso procesal y ejecución de sentencia.
